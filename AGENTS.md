## ENFORCEMENT RULES (MANDATORY)

### Phase Gates
Before starting Phase N, you MUST have the prerequisite artifacts complete:

| Phase | Prerequisite | Gate Check |
|-------|-------------|------------|
| 0 - Research | - | Start here |
| 1 - Design Read | PROJECT_BRIEF.md filled | >=3 research reference points |
| 2 - Skills Consult | DESIGN_READ.md dials set | All Required skills in SKILLS_MANIFEST.md marked `[x]` |
| 3 - Build | SKILLS_MANIFEST.md complete | No raw hex/values in component CSS |
| 4 - Verify | Code complete | PREFLIGHT.md all items checked |
| Done | PREFLIGHT.md complete | QUALITY_REPORT.md filled with verdict SHIP |

### The Rules
1. **Read `SKILLS_MANIFEST.md` before any code change.** This file lists every skill you must load.
2. **Every Required skill with `[ ]` unchecked = STOP.** Load it before continuing.
3. **Cross-deps must be loaded first.** If `impeccable` depends on `design-skill-execution`, load the dependency first.
4. **Optional skills with missing deps = skip gracefully.** Note the skip in QUALITY_REPORT.md.
5. **Do not free-hand "taste".** Derive direction from the design skills + `DESIGN.md`.
6. **No raw values in components.** All colors, sizes, and fonts come from `css/tokens.css`.
7. **Bounded verification passes.** Inspect once (desktop+mobile), fix in one batch, confirm at most once, STOP.

## Do / Don't
- DO fill `docs/PROJECT_BRIEF.md` with real research before building.
- DO load all Required skills before writing HTML/CSS/JS.
- DO run `docs/PREFLIGHT.md` before declaring done.
- DO fill `QUALITY_REPORT.md` as proof the pipeline ran.
- DON'T free-hand "taste" - derive direction from the design skills + `DESIGN.md`.
- DON'T add frameworks unless the brief justifies them.
- DON'T skip a phase gate - the gate exists to prevent bad output.
- DON'T use AI writing patterns: zero em dashes, no "delve/leverage/harness/empower/seamless/scalable/innovative", no "Here's the thing:" / "Let's dive in:" openers, no generic SaaS copy like "Built for modern teams".
